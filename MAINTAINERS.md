Maintainers
===========

This file lists who looks after this repository and its releases.  A role
marked *vacant* has nobody in it yet; anyone willing to take one on can say so
in an issue or pull request.

| Role | What it involves | Who |
|---|---|---|
| Maintainer | Reviews and merges pull requests, keeps the build working, answers issues. | *vacant* |
| Release builder | Builds each release, signs its `SHA256SUMS`, and keeps a key in [`contrib/gitian-keys/`](divi/contrib/gitian-keys/README.md). See [release-signing.md](divi/doc/release-signing.md). | *vacant* |
| Second builder | Rebuilds each release independently and checks the hashes match before it is published. | *vacant* |
| Security contact | Receives reports of security problems privately and coordinates a fix. | *vacant* |

Until the security contact is filled, please do not report a security problem
in a public issue.  Open an issue asking for a private contact instead, without
the details.
